## 🚀 How to Update Your Live Website

### ✨ The Easy Way (Recommended for Everyone)

**Use Lovable Dashboard:**

1. Go to [lovable.dev](https://lovable.dev)
2. Log in to your account
3. Open your "Asper Beauty Shop" project
4. Make changes using:
   - Visual editor (click and edit)
   - AI prompting (describe what you want)
5. **That's it!** Your changes go live automatically! 🎉

**Changes appear on your live site in about 2-5 minutes.**

### 💼 The Developer Way (For Technical Users)

**Use GitHub:**

1. Clone: `git clone https://github.com/asperpharma/asperbeauty.git`
2. Edit code locally
3. Test: `npm run dev`
4. Push to GitHub: `git push`
5. Lovable auto-deploys your changes

## 🌐 Using Your Own Domain

Want to use **asperbeautyshop.com** instead of **asperbeautyshop.lovable.app**?

**Steps:**
1. Go to Lovable Dashboard → Settings → Custom Domain
2. Enter your domain name (e.g., asperbeautyshop.com)
3. Lovable will show you DNS settings
4. Add those DNS settings to your domain registrar (GoDaddy, Namecheap, etc.)
5. Wait 24-48 hours for DNS to update
6. Done! Your site will work on your custom domain
